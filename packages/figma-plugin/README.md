# Figma Plugin for andrsrxn/icons

</div>

## Overview

Oficial Figma plugin. Paste all the SVG from `andrsrxn/icons` into your canvas, available on **Figma and FigJam**.

## Installation

Visit [andrsrxn/icons on Figma Community](https://www.figma.com/community/plugin/1682600602773496009) or search **andrsrxn/icons** in the `Plugins & widgets` panel in Figma or FigJam.

## Features

- Search any icon by name, tag or category
- Filter by group (UI or Flags)
- Insert icons as real, editable vector layers on the canvas

## How to Use

1. Open the plugin
2. Search for an icon
3. Click the icon to insert it into the canvas
